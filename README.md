# Rift Form Lab

An evidence-aware, frame-by-frame distance-running mechanics studio. The model is tuned to a 190 cm runner and draws on measured elite Kenyan and East African gait research without claiming that any nation or athlete has one fixed running style.

## What is included

- Phase-authored side and rear-view running models
- Pace-specific cadence, contact, flight and step-length mechanics
- Centre-of-mass, joint, force, posture and motion-trail overlays
- Six stride landmarks with scrubbing and slow-motion playback
- A contrast lab for over-reach, waist fold and crossover patterns
- Primary-study notes and model boundaries
- Responsive, keyboard-accessible and offline-capable static build

## Run locally

```bash
npm run serve
```

Then open `http://localhost:4173`.

## Test

```bash
npm test
```

No build step or external runtime dependency is required.
