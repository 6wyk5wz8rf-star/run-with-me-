# Rift Form Lab

An evidence-aware, frame-by-frame distance-running mechanics studio. The adjustable 190 cm figure is an illustrative reference, not measured national anatomy. Research involving Kenyan, Ethiopian, Eritrean and other runners informs the app’s evidence boundaries without claiming that any nation or athlete has one fixed running style.

## What is included

- Phase-authored side and rear-view running models
- A calm coaching loop: choose → see → feel → let go → notice
- Seven felt-problem pathways and 28 concise cues with a separate watch, feel, boundary and release layer
- A useful “Today’s cue” saved only when the runner reports that it felt easier
- Contextual adjustments for rhythm, stack angle, landing offset, running lane and inward arm path
- Continuous reciprocal arms with a bounded, adjustable inward path
- Continuous leg and foot paths through touchdown, toe-off and stride wrap
- Support-foot travel matched to pace multiplied by contact time
- Rigid feet with ankle readouts calculated from the rendered geometry
- Mass-weighted centre of mass and impulse-balanced ground-force traces
- A true mid-stance event aligned with the support foot rather than an arbitrary percentage
- Pace-specific cadence, contact, flight and step-length mechanics
- Centre-of-mass, joint, force, posture and motion-trail overlays
- Six stride landmarks with scrubbing and slow-motion playback
- A contrast lab for over-reach, waist fold and crossover patterns
- Primary-study notes and model boundaries
- Portrait canvas cameras and readable annotations for mobile, tablet and desktop
- Responsive, keyboard-accessible and offline-capable source and production builds
- Device-local preference saving with a complete reset to the pace model

## Run locally

```bash
npm run serve
```

Then open `http://localhost:4173`.

## Test

```bash
npm test
```

No build step is required for local source use. `npm run build` creates the production bundle and its matching offline cache.
